# Retired Node implementation

Preserved source from the earlier Node.js backend and its tests for migration reference only. This directory is not part of the C# solution, is not invoked by QA Studio, and is not a supported launch target. The tests retain historical paths and are not the current validation suite.

Use `dotnet run --project src/QaStudio.Web` from Demo. The maintained C# integration suite is `tests/QaStudio.IntegrationTests`.
